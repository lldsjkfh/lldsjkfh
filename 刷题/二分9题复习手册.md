# 二分 · 9 题复习手册

> 一套骨架，9 道题。差异只有三处：边界取闭还是半开、返回 `mid` 还是继续二分、找不到时返回什么。
> 语言：C++17。题号对应 LeetCode 中国站。

## 0 先行约定

二分的所有坑都来自「混用两套约定」。**同一份代码里只能选一套**：

| 约定 | 区间写法 | 循环条件 | 收缩方式 | 循环结束时 `l` |
| --- | --- | --- | --- | --- |
| 闭区间 | `[l, r]`，初值 `0, n-1` | `l <= r` | `l = mid + 1` / `r = mid - 1` | 越界 1 位 |
| 半开区间 | `[l, r)`，初值 `0, n` | `l < r` | `l = mid + 1` / `r = mid` | 第一个满足条件的位置 |

求 `mid` 一律写 `mid = l + (r - l) / 2`（下取整），避免 `(l + r)` 溢出。配合下取整时，**收缩必须是 `l = mid + 1`**，否则 `l == mid` 会死循环。

### 统一骨架

```cpp
int l = 0, r = 初始右界, ans = 兜底值;
while (l <= r) {                      // 或 l < r
    int mid = l + (r - l) / 2;
    if (ok(mid)) { ans = mid; l = mid + 1; }   // 找边界：先记答案再继续
    else         { r = mid - 1; }              // 找值：直接 return mid
}
return ans;                            // 或 return l;
```

三个决策点：

1. **边界取开还是闭** —— 取决于「答案是不是一定在数组里」。`704` 找具体值用闭区间；`35` 找插入点用半开区间返回值就是 `l`。
2. **要不要立刻返回** —— 找「任意一个」就直接 `return mid`；找「第一个/最后一个」必须用 `ans` 记下来继续二分，因为当前的 `mid` 未必是边界。
3. **找不到返回什么** —— `-1`、`l`（插入点）、`l == n ? 0 : a[l]`（循环数组）各不相同，写之前先想清楚。

## 基础 5 题 · 模板与边界

### 704. 二分查找

最干净的模板基线，用来固定「闭区间 + 立即返回」这套写法。

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int l = 0, r = (int)nums.size() - 1;   // 闭区间 [l, r]
        while (l <= r) {
            int mid = l + (r - l) / 2;
            if (nums[mid] == target) return mid;
            if (nums[mid] < target)  l = mid + 1;
            else                     r = mid - 1;
        }
        return -1;
    }
};
```

- 复杂度：时间 O(log n)，空间 O(1)
- 易错点：`r` 写成 `n` 却仍用 `l <= r`，会越界访问 `nums[n]`

### 34. 在排序数组中查找元素的第一个和最后一个位置

**找到不要返回**，要往左/右继续二分。标准做法是拆成 `lower_bound` 与 `upper_bound` 两个函数。

```cpp
class Solution {
    // 第一个 >= t 的位置
    int lower(vector<int>& a, int t) {
        int l = 0, r = (int)a.size();          // 半开 [l, r)
        while (l < r) {
            int mid = l + (r - l) / 2;
            if (a[mid] < t) l = mid + 1;
            else            r = mid;
        }
        return l;
    }
    // 第一个 > t 的位置
    int upper(vector<int>& a, int t) {
        int l = 0, r = (int)a.size();
        while (l < r) {
            int mid = l + (r - l) / 2;
            if (a[mid] <= t) l = mid + 1;
            else             r = mid;
        }
        return l;
    }
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        int lo = lower(nums, target);
        if (lo == (int)nums.size() || nums[lo] != target) return {-1, -1};
        return {lo, upper(nums, target) - 1};
    }
};
```

- 复杂度：O(log n) / O(1)
- 易错点：`lower` 返回 `n` 时必须先判越界再取 `nums[lo]`；`upper - 1` 才是最后一个位置

### 35. 搜索插入位置

**找不到时返回 `l`，正好就是插入点**——这是半开区间写法最漂亮的性质，不需要额外判断。

```cpp
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int l = 0, r = (int)nums.size();
        while (l < r) {
            int mid = l + (r - l) / 2;
            if (nums[mid] < target) l = mid + 1;
            else                    r = mid;
        }
        return l;                              // 元素全小于 target 时 l == n，也对
    }
};
```

- 复杂度：O(log n) / O(1)
- 易错点：用闭区间写法时，循环结束后要额外判断 `nums[l] >= target ? l : l + 1`，容易漏

### 744. 寻找比目标字母大的最小字母

练「循环不变量」：区间 `[l, r)` 内始终是「可能成为答案」的候选，所以收缩时把 `mid` 本身保留在右半区。

```cpp
class Solution {
public:
    char nextGreatestLetter(vector<char>& letters, char target) {
        int l = 0, r = (int)letters.size();
        while (l < r) {
            int mid = l + (r - l) / 2;
            if (letters[mid] <= target) l = mid + 1;
            else                        r = mid;
        }
        return l == (int)letters.size() ? letters[0] : letters[l];  // 都比 target 小 → 回绕
    }
};
```

- 复杂度：O(log n) / O(1)
- 易错点：注意是「严格大于」（`<=` 才右移），以及末尾回绕

### 2529. 正整数和负整数的最大计数

两次二分找 `0` 的分界，把「数个数」变成「找位置」，O(log n) 而不是 O(n)。

```cpp
class Solution {
public:
    int maximumCount(vector<int>& nums) {
        int n = (int)nums.size();
        int firstNonNeg = lower_bound(nums.begin(), nums.end(), 0) - nums.begin(); // 第一个 >= 0
        int firstPos    = upper_bound(nums.begin(), nums.end(), 0) - nums.begin(); // 第一个 > 0
        int negatives = firstNonNeg;          // 0 之前全是负数
        int positives = n - firstPos;         // 0 之后全是正数
        return max(negatives, positives);
    }
};
```

- 复杂度：O(log n) / O(1)
- 易错点：`0` 既不算正也不算负，不能直接用 `firstNonNeg` 算正数

## 进阶 4 题 · 先排序再二分

这 4 题共同的结构是：**答案不能直接在原数组上二分，需要先在有序结构里定位，或者把「判定」改写成单调谓词。**

### 1385. 两个数组间的距离值

判定改写成「在有序的 `arr2` 里找是否存在落在 `[x-d, x+d]` 的元素」——一个 `lower_bound` 就够。

```cpp
class Solution {
public:
    int findTheDistanceValue(vector<int>& arr1, vector<int>& arr2, int d) {
        sort(arr2.begin(), arr2.end());        // O(m log m)
        int ans = 0;
        for (int x : arr1) {
            auto it = lower_bound(arr2.begin(), arr2.end(), x - d);  // 第一个 >= x-d
            if (it == arr2.end() || *it > x + d) ans++;              // 区间内没有元素
        }
        return ans;
    }
};
```

- 复杂度：O((n + m) log m)，空间 O(1)
- 易错点：只需查**一个**候选（第一个 `>= x-d` 的），它的前一个必然 `< x-d`，不用两头都查

### 1170. 比较字符串最小字母出现频次

先算频次，排序后对每个查询用 `upper_bound` 数「严格大于」的个数。

```cpp
class Solution {
    int f(const string& w) {
        char c = *min_element(w.begin(), w.end());
        return (int)count(w.begin(), w.end(), c);
    }
public:
    vector<int> numSmallerByFrequency(vector<string>& queries, vector<string>& words) {
        vector<int> fw;
        for (auto& w : words) fw.push_back(f(w));
        sort(fw.begin(), fw.end());

        vector<int> ans;
        for (auto& q : queries) {
            int t = f(q);
            ans.push_back((int)(fw.end() - upper_bound(fw.begin(), fw.end(), t)));
        }
        return ans;
    }
};
```

- 复杂度：O(L + m log m + n log m)，L 为所有字符串总长
- 易错点：题目要的是**严格大于**，用 `upper_bound` 而不是 `lower_bound`；频次是「最小字母」出现的次数，不是最小频次

### 2300. 咒语和药水的成功对数

对每个 `spell` 反解出「药力至少要多大」，再在排序后的 `potions` 上 `lower_bound` 数后缀。

```cpp
class Solution {
public:
    vector<int> successfulPairs(vector<int>& spells, vector<int>& potions, long long success) {
        sort(potions.begin(), potions.end());
        int m = (int)potions.size();
        vector<int> ans;

        for (int s : spells) {
            long long need = (success + s - 1) / s;     // ceil(success / s)，注意先转 long long
            if (need > potions.back()) { ans.push_back(0); continue; }
            int idx = lower_bound(potions.begin(), potions.end(), (int)need) - potions.begin();
            ans.push_back(m - idx);
        }
        return ans;
    }
};
```

- 复杂度：O((n + m) log m)，空间 O(1)
- 易错点：`success` 最大 1e10，`s * p` 必须用 `long long`；向上取整写成 `(success + s - 1) / s` 且 `s` 要先提升为 64 位

### 2389. 和有限的最长子序列

排序 + 前缀和之后，问题变成「找最大的 `k` 使 `pre[k] <= q`」——一个「找最后一个满足条件的」二分，正好用 `ans` 记答案。

```cpp
class Solution {
public:
    vector<int> answerQueries(vector<int>& nums, vector<int>& queries) {
        sort(nums.begin(), nums.end());
        int n = (int)nums.size();
        vector<long long> pre(n + 1, 0);
        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + nums[i];

        vector<int> ans;
        for (int q : queries) {
            int l = 0, r = n, best = 0;
            while (l <= r) {
                int mid = l + (r - l) / 2;
                if (pre[mid] <= q) { best = mid; l = mid + 1; }  // 还能更长
                else               { r = mid - 1; }
            }
            ans.push_back(best);
        }
        return ans;
    }
};
```

- 复杂度：O((n + m) log n)，空间 O(n)
- 易错点：求「子序列」不是子数组，所以排序不改变答案；`pre` 用 `long long` 防溢出；找的是「最后一个满足」而非「第一个满足」，`ans` 初值必须是 0

## 反复踩到的三个坑

1. **边界混用**：`r = n` 却写 `l <= r` → 越界；`r = n - 1` 却写 `l < r` → 漏掉最后一个元素。写之前先念一遍「闭区间配 `<=`，半开配 `<`」。
2. **死循环**：`mid` 下取整时写成 `l = mid`。下取整意味着 `mid` 可能等于 `l`，必须 `l = mid + 1` 才能保证区间收缩。
3. **该记答案却在返回**：找「第一个/最后一个」时直接 `return mid`，结果拿到的是中间某个满足条件的元素。只要题目出现「最左 / 最右 / 最长 / 最短」，就一定要用 `ans` 记。
