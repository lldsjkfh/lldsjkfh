# 论文精读

深度学习 / 算法 / 系统方向的论文精读笔记，按论文一篇一个文件整理。

## 笔记约定

每篇论文建议包含：

- **论文信息**：标题、作者、会议/期刊、年份、原文链接
- **一句话总结**：这篇论文解决了什么问题
- **核心贡献**：2~4 条
- **方法要点**：关键设计、公式、图示
- **实验结论**：主要数据集与指标对比
- **我的思考**：可借鉴之处、局限、可延伸的方向
